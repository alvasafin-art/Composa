# Basic Editing

Install `plugin.json` through Plugins > Manage / Install Plugins.

- Blue Card adds a live rounded rectangle and editable text in a group.
- Duplicate and Offset copies the selected layer/group and moves it 20 pixels.

Each command is one Undo step. No model, ComfyUI, export permission or extra dependency is needed. Assign shortcuts in Help > Keyboard Shortcuts. These examples are covered by the repository's MIT license.
