# Диагностика задержек Composa Studio 17.21

База — `main` на коммите `fde9ab4` (PR #38). Измерения сделаны в Release на Windows x64 с 12 логическими процессорами. Для композитора использован растровый Skia с отключённым OpenCL. Сценарии интерфейса прошли в Avalonia Headless с окном 1440 × 900. Время кадра учитывает обработку ввода и отрисовку холста до конца callback. Физическую задержку пера, GPU-презентацию и показ кадра монитором нужно измерять на обычном окне.

## Исправленные причины

- Смешивание RGB16 для корректирующих слоёв и групп читало ширину и шаг растра через Skia в пиксельном цикле. Теперь размеры и шаг берутся один раз, а пиксели читаются из текущей строки. Измерено на корректирующем слое «Инверсия» с тремя вариантами покрытия. Остальные корректировки и проходные группы используют тот же этап смешивания.
- Кэш эффектов удерживал максимум 12 изображений, даже если стек целиком помещался в его бюджет памяти. На 21 кадр с 16 такими слоями после прогрева пришлось 336 повторных вычислений эффектов, а с 24 слоями — 504. Кэш теперь допускает до 128 записей, сохраняет бюджет 384 МиБ и прежнее исключение для одного результата крупнее бюджета. В обоих сценариях после прогрева повторных вычислений стало 0. В тесте из 8 слоёв кэш и раньше вмещал весь стек.
- Растушёванная маска проходила медленный пересчёт плотности даже при 100%. При меньшей плотности теперь используется таблица для всех 256 значений Alpha8 с прежним округлением. В замере остаётся стоимость самой растушёвки Skia.
- Те же обращения к Skia были в подготовке «Наложения цвета» RGB8/RGB16 и в каждом сэмпле размытия в движении RGB16. Размеры считываются один раз, перед обработкой пикселей.

### Где проверять архитектуру дальше

1. **Кадр и GPU.** Обычный путь `CanvasView.UpdateViewCache → EditorSession.RenderViewportFrame → DocumentRenderer.RenderCpu` готовит буфер синхронно при записи операции отрисовки. CPU ведёт композицию полосами и копирует их в буфер показа. При малой правке вызов холста сегодня не передаёт полный размер стабильной сетки полос. Нужно измерить стабильные тайлы с обработкой ореолов и отменяемую фоновую подготовку кадра, сверяя с итоговым рендером. В приложении GPU-презентация используется при подходящих сценах во время навигации и перемещения ниже 100% для sRGB RGB8. OpenCL-композиция при масштабе 100% работает с ограниченным набором слоёв и режимов и читает результат обратно в CPU. Их покрытие и цену нужно зафиксировать трассировкой в обычном окне с включённым и выключенным GPU.
2. **Warp и кисти на крупных проектах.** Для Warp измерить отдельно приготовление сетки, генерацию растрового представления, маски и композитинг. Текущее отсечение отдельных участков сетки при 100% сохраняет полную выходную поверхность. Для кистей разделять первый отпечаток, промежуточные события и фиксацию. Повторить на RGB8 и RGB16, со стилями, маской, выделением и заблокированной прозрачностью.
3. **Холодные эффекты и фильтры.** Предпросмотр крупного слоя может сначала собрать полноразмерный эффект и лишь затем уменьшить его. Сравнить вычисление на уровне масштаба просмотра и пересчёт только затронутой области с ореолом. Полноразмерный результат и рабочий профиль проверять отдельно.

## Воспроизведение

Подготовка пакетов и моделей описана в [инструкции стенда холста](canvas-replay.txt). Для проверки композитора исходный каталог передаётся явно, поэтому один и тот же стенд можно запустить на любой из двух сборок. Запускайте последовательно из ветки с этим стендом.

```powershell
dotnet run --project scripts/performance/CompositorLatency -c Release -p:CanvasPerformance=true -p:ComposaSourceRoot=C:/bench/composa-main
dotnet run --project scripts/performance/CompositorLatency -c Release -p:CanvasPerformance=true
```

Стенд выводит медиану, p95, счётчик расчётов эффектов и SHA-256 растра. Для измерений окна используйте пять сценариев существующего стенда. Для повторяемой оценки p95 нужны отдельные прогоны каждого сценария. Таблица выше описывает один диагностический проход.

```powershell
pwsh -File scripts/performance/Run-CanvasPerformance.ps1 -DataDirectory C:/bench/composa -Label main -GenerateFixtures -Scenario interaction,tools,card,banner,photo
```
