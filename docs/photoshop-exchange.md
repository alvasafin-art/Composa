# Обмен изображениями с Photoshop

Для Windows, Composa preview.22 и новее. Обновите и приложение, и Exchange.ps1. Откройте обе программы под одним пользователем Windows. Включать **Allow AI Control** не требуется: обмен использует отдельное локальное соединение только для открытия и экспорта изображений.

## Из Composa в Photoshop

В **Scripts → Run Script File…** выберите **Send-to-Photoshop.js** из scripts/photoshop и запустите его. Обычный .js виден в диалоге JavaScript Composa. Также работает Send-to-Photoshop.cmd из проводника.

Передаётся **общий видимый результат всего документа**, как после сведения слоёв: с масками, прозрачностью, эффектами и смешиванием. Выделение и активный слой не ограничивают экспорт. Исходные слои, путь сохранения и история остаются прежними; Photoshop открывает временный PNG новым документом.

Для передачи слоёв запустите **Send-layers-to-Photoshop.js** в Composa. Photoshop открывает временную PSD-копию с группами, слоями, масками, текстом и векторами, которые поддерживает PSD-экспорт. Неподдерживаемые живые эффекты и зависимые от нижних слоёв корректировки сохраняются через совместимое растровое представление; программа сообщает о преобразованиях. Исходный .cmps остаётся источником всех нативных параметров. Из PowerShell тот же экспорт доступен через `Exchange.ps1 -Direction ToPhotoshop -Layers`.

Держите Exchange.ps1 рядом со скриптами. Обмен подключается прямо к работающей Composa; искать composa.exe и задавать COMPOSA_EXE больше не требуется. Используется отдельный канал обмена изображениями, без общего AI Control. Приложение-получатель восстанавливается из свёрнутого состояния и активируется после открытия изображения. Windows может ограничить передачу фокуса между приложениями с разными правами; запускайте оба обычным способом от одного пользователя.

## Из Photoshop в Composa

В Photoshop выберите **File → Scripts → Browse…** и откройте **Send-to-Composa.js**. Вариант .jsx оставлен для совместимости. Оба предназначены для Photoshop; в Composa запускается Send-to-Photoshop.js.

Держите Photoshop-скрипт и Exchange.ps1 в одной папке из полного архива. Photoshop создаёт сведённый дубликат активного документа, переводит копию в RGB / 8 бит, сохраняет PNG и передаёт его в открытый редактор новой вкладкой. Исходный документ не изменяется.

## Проверки и ограничения

### Windows Server / RDP

Прежнее имя `composa-image-exchange` относилось ко всей машине. Другой пользователь пытался открыть/создать экземпляр канала первого пользователя, чей доступ ограничен владельцем, и получал Access denied. Теперь обе стороны получают `[WindowsIdentity]::GetCurrent().User.Value` и используют **`composa-image-exchange-<SID>`**. Общий MCP-канал также использует `composa-mcp-<SID>`. Unix-сокеты по-прежнему находятся в каталоге кэша пользователя.

Канал имеет защищённый ACL: полный доступ только SID текущего пользователя, владелец — тот же SID, сетевые подключения запрещены через Network SID. Клиенты проверяют SID владельца сервера. Не нужны права администратора или разрешение Everyone. Photoshop ищется и активируется только в текущем Windows-сеансе. `COMPOSA_EXCHANGE_PIPE` / `COMPOSA_MCP_PIPE` оставлены для тестов и специализированной настройки; общий принудительный override на сервере отменит изоляцию по SID, поэтому обычно их следует убрать.

На сервере откройте одновременно два RDP-сеанса **разных учётных записей**, в каждом запустите обновлённую Composa и Photoshop обычным способом. Для проверки:

1. В каждом сеансе выполните `[Security.Principal.WindowsIdentity]::GetCurrent().User.Value`: SID и соответствующие имена каналов должны различаться.
2. Создайте разные тестовые изображения и одновременно отправьте их в Photoshop через Send-to-Photoshop.js, затем назад через Send-to-Composa.js. Каждое изображение должно появиться только в своём сеансе; Access denied быть не должно.
3. Отправьте Send-layers-to-Photoshop.js: проверьте группы и маски в PSD, исходную историю и путь .cmps.
4. Закройте Composa одного пользователя: обмен второго должен продолжить работать. Повторите после переподключения RDP.

Два сеанса одной учётной записи имеют один SID и один канал: в таком случае обслуживает первая Composa этого пользователя. Это изоляция по пользователю, а не по SessionId.

В локальных проверках использовалась Windows 11 Home: проверены параллельные отдельные имена каналов, SID владельца, защищённый ACL и двусторонние байтовые сообщения, а также настоящий Exchange.ps1 с работающим тестовым редактором. Проверка **разными пользователями через настоящий Windows Server/RDP пока не выполнена**, поскольку такой сервер недоступен. Область имён Named Pipes и запрет Network SID описаны в [документации Microsoft](https://learn.microsoft.com/windows/win32/ipc/named-pipes). Явный SID пользователя также избегает зависимости от группового Owner в CurrentUserOnly ([dotnet/runtime](https://github.com/dotnet/runtime/issues/123903)).

В автоматической проверке запускался настоящий поставляемый Exchange.ps1, подключавшийся прямо к каналу обмена открытого редактора при выключенном AI Control. Проверены общий экспорт нескольких слоёв при активном выделении, точное совпадение пикселей, неизменность исходной истории и открытие PNG новой вкладкой. Проверены PowerShell-синтаксис и JavaScript-файл Composa.

Photoshop не установлен в среде этих проверок, поэтому его COM-интерфейс и ExtendScript DOM требуют проверки на вашей версии. Мост сначала подключается к запущенному COM-объекту, затем использует зарегистрированный Photoshop COM-интерфейс, если объект не опубликован. Если Photoshop не запущен, передача завершается понятной ошибкой. Эти файлы запускаются через **File → Scripts**, а не как UXP-плагин.

Обычный обмен использует сведённый PNG; отдельный Send-layers-to-Photoshop.js — PSD. Профили и перевод в 8 бит могут влиять на цвет. Временные PNG/PSD остаются в системной временной папке, пока открыты в редакторах; после закрытия их можно удалить. [Документация Adobe по скриптам](https://helpx.adobe.com/photoshop/desktop/automate-tasks/automation-settings-and-presets/automate-photoshop-with-scripts.html), [UXP API](https://developer.adobe.com/photoshop/uxp/ps_reference/).
