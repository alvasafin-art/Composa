# Обмен изображениями с Photoshop

Для Windows, Composa preview.20 и новее. Откройте обе программы под одним пользователем Windows. Включать **Allow AI Control** не требуется: обмен использует отдельное локальное соединение только для открытия и экспорта изображений.

## Из Composa в Photoshop

Выберите **File → Send Image to Photoshop**. Либо в **Scripts → Run Script File…** выберите **Send-to-Photoshop.js** из scripts/photoshop и запустите его. Обычный .js виден в диалоге JavaScript Composa. Также работает Send-to-Photoshop.cmd из проводника.

Передаётся **общий видимый результат всего документа**, как после сведения слоёв: с масками, прозрачностью, эффектами и смешиванием. Выделение и активный слой не ограничивают экспорт. Исходные слои, путь сохранения и история остаются прежними; Photoshop открывает временный PNG новым документом.

Для ярлыка скрипты должны лежать в scripts/photoshop внутри полного распакованного архива рядом с composa.exe. При другом расположении задайте COMPOSA_EXE или -ComposaExe для Exchange.ps1. Отправка непосредственно из Composa не требует поиска её исполняемого файла.

## Из Photoshop в Composa

В Photoshop выберите **File → Scripts → Browse…** и откройте **Send-to-Composa.js**. Вариант .jsx оставлен для совместимости. Оба предназначены для Photoshop; в Composa запускается Send-to-Photoshop.js.

Держите Photoshop-скрипт и Exchange.ps1 в одной папке из полного архива. Photoshop создаёт сведённый дубликат активного документа, переводит копию в RGB / 8 бит, сохраняет PNG и передаёт его в открытый редактор новой вкладкой. Исходный документ не изменяется.

## Проверки и ограничения

В автоматической проверке запускался настоящий поставляемый Exchange.ps1, подключавшийся через настоящий composa --exchange к открытому редактору при выключенном AI Control. Проверены общий экспорт нескольких слоёв при активном выделении, точное совпадение пикселей, неизменность исходной истории и открытие PNG новой вкладкой. Проверены PowerShell-синтаксис и JavaScript-файл Composa.

Photoshop не установлен в среде этих проверок, поэтому его COM-интерфейс и ExtendScript DOM требуют проверки на вашей версии. Мост сначала подключается к запущенному COM-объекту, затем использует зарегистрированный Photoshop COM-интерфейс, если объект не опубликован. Если Photoshop не запущен, передача завершается понятной ошибкой. Эти файлы запускаются через **File → Scripts**, а не как UXP-плагин.

Передаётся изображение, а не редактируемые слои. Для слоёв используйте PSD. Профили и перевод в 8 бит могут влиять на цвет. Временные PNG остаются в системной временной папке, пока открыты в редакторах; после закрытия их можно удалить. [Документация Adobe по скриптам](https://helpx.adobe.com/photoshop/desktop/automate-tasks/automation-settings-and-presets/automate-photoshop-with-scripts.html), [UXP API](https://developer.adobe.com/photoshop/uxp/ps_reference/).
