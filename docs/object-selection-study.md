# Как Composa выбирает предмет и уточняет его края

В Studio 16.6 клик по торцу рулона пастилы мог аккуратно выделить один торец. У рамки вокруг ряда ананасов ошибка возникала позже: модель находила ломтики, но при уточнении границы их середина становилась почти прозрачной. В Studio 16.7 эти два случая обрабатываются на разных этапах. Всё работает локально на уже поставляемых EfficientSAM ViT-S и ViTMatte Small.

## Как пользоваться

Выберите **Object Selection → Automatic · Local**. Щёлкните внутри отдельного предмета. Если предметы соприкасаются или один перекрывает другой, обведите нужный предмет рамкой с небольшим запасом. Для нескольких ломтиков проведите одну рамку вокруг всего ряда. Для текста на плашке охватите рамкой буквы. При выделении волос и шерсти оставьте в кадре фон около края. Чтобы оценить результат, скопируйте выделенное на новый слой через **Ctrl+J** и подложите по очереди светлый и тёмный фон. Так видны и потерянные волоски, и цветная кайма. [Режимы выделения и цвет края](object-selection-models.md)

## Как устроено выделение

1. **Выбор масштаба объекта.** EfficientSAM предлагает несколько масок для одной точки. Торец, весь рулон и предмет вместе с соседями могут содержать пиксель клика. Если две альтернативы согласуются по форме и включают первоначальную деталь, Composa делает второй запрос точкой на предполагаемом теле предмета. Для перехода к целому нужно совпадение повторной маски как минимум на 85% по IoU. В другой неоднозначной ситуации Composa проверяет рамкой границы связного участка под курсором. Это помогает отличить глазурь от пончика и небольшое соцветие от всей тарелки. Дополнительные запросы используют уже вычисленные признаки изображения. [Код проверки гипотез](../src/Composa.Core/Vision/PointMaskCandidates.cs) · [EfficientSAM, реализация авторов](https://github.com/yformer/EfficientSAM)
2. **Сохранение непрозрачной середины.** ViTMatte получает изображение и карту с тремя зонами — предмет, фон и полоса неопределённости. На узких дольках эта полоса иногда покрывает почти весь предмет. Composa сравнивает результат с исходным силуэтом. Если исчезло более четверти его пикселей и после сужения контура осталось менее 12% уверенной сердцевины, алгоритм может повторить обработку с более узкой полосой. Для принятия результата должно сохраниться не менее 80% силуэта. Проверки плотности силуэта и цвета штрихов защищают открытые контуры и надписи. [Реализация уточнения](../src/Composa.Core/Vision/PromptSegmentation.cs) · [ViTMatte, реализация авторов](https://github.com/hustvl/ViTMatte)
3. **Буквы и мягкие края.** В надписях повторяются штрихи близкого цвета. Composa оценивает цвет фона около каждого края и восстанавливает покрытие штриха с учётом этого фона. Так сохраняются просветы букв на неоднородной поверхности. На шерсти и волосах сохраняется дробная прозрачность. При копировании вырезки цвет краевых пикселей дополнительно корректируется по окружающим цветам — это уменьшает оттенок прежнего фона. [Выделение печатной графики](../src/Composa.Core/Vision/GraphicSelection.cs) · [Оценка покрытия](../src/Composa.Core/Vision/ForegroundCoverage.cs)

## Что изменилось на фотографиях

На пяти фотографиях COCO128-seg проверены 15 отдельных предметов — пончики, морковь, брокколи, стаканы и хот-доги. Каждый предмет выделялся кликом и рамкой. IoU — площадь пересечения маски с разметкой, делённая на площадь их объединения. Таблица показывает среднее по жестам. Это небольшая выборка, которая использовалась при разработке.

| Жест и число случаев | Studio 16.6 | Studio 16.7 | Photoshop 2026 |
| --- | ---: | ---: | ---: |
| Клик, все 15 | 49,4% | 65,5% | — |
| Клик, 13 с сохранённой маской Photoshop | 42,4% | 61,0% | 51,7% |
| Рамка, все 15 | 84,1% | 84,7% | 72,4% |

На одном пончике IoU по клику вырос с 47,4% до 95,3%, на одном соцветии брокколи — с 1,6% до 75,2%. Остались ошибки. На одном хот-доге клик всё ещё выбирает только горчицу, хотя рамка даёт 96,2%. На небольшом кусочке моркови результат рамки снизился с 67,9% до 67,1%. Для двух кликов по стаканам отсутствует маска Photoshop. [Координаты и результаты каждого жеста](object-selection-coco.csv)

Отдельно проверены 27 жестов на фотографии дегидратора. Там нет ручной разметки, поэтому сравнивали вырезки визуально. При клике по торцу тёмного рулона теперь выделяется весь видимый рулон. Рамка сохраняет середины клубники и ананасов. Задний рулон, перекрытый мятой, всё ещё выделяется частично, а под рядом малины иногда захватывается полоска соседних фруктов. На 104 прежних контрольных масках, включая текст, шерсть и обод тарелки, значения прозрачности совпали с сохранёнными результатами побайтно.

## Как повторить сравнение

1. Скачайте **COCO128-seg**, откройте исходный JPEG по числовому ID из CSV (например, `000000000438.jpg`). В CSV каждая строка содержит номер строки полигона в одноимённом файле меток, начиная с нуля. [Описание набора и разметки](https://docs.ultralytics.com/datasets/segment/coco128-seg/)
2. В обеих версиях откройте JPEG в исходном размере одним слоем. Выберите **Automatic · Local**, режим замены выделения. Используйте координаты из CSV в пикселях документа от левого верхнего угла. Для точки заданы X и Y, для рамки — левая, верхняя, правая и нижняя границы, последние две исключаются. Точки выбирались в наиболее удалённом от контура пикселе разметки. Рамки построены по границам разметки с запасом в три пикселя. Такая проверка измеряет результат при точном указании цели.
3. Для численного сравнения сохраните альфа-канал вырезки на холсте исходного размера. Растеризуйте полигон с помощью Pillow `ImageDraw.polygon`, умножив нормализованные координаты на ширину и высоту JPEG. Пиксель маски принадлежит объекту при альфе ≥128 из 255. Вычислите IoU каждого жеста и усредните отдельно клики и рамки. Для проверки волос дополнительно сравните полную 8-битную альфу и вид на двух фонах: пороговая метрика теряет полупрозрачные детали.
4. Для программного повтора используйте `EditorSession.SelectPromptObjectAsync` с `PromptModels.EfficientSamS`, `SelectionMode.Replace` и `preciseEdges: true`. В серии проверки три результата дополнительно воспроизвели жестами мыши через окно Composa: торец рулона, ряд ананасов и пончик. Во всех трёх случаях маска совпала с результатом вызова ядра.
