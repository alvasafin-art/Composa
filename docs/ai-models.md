# Модели и подключение ComfyUI

Composa не загружает веса генеративных моделей самостоятельно. Их загружает сервер ComfyUI. Клиент получает точные доступные имена от узлов сервера через `/object_info`, включая подпапки и дополнительные хранилища, зарегистрированные в ComfyUI.

## Настройка

1. Запустите ComfyUI и убедитесь, что его страница открывается в браузере.
2. В Composa откройте **AI → ComfyUI Settings** и укажите полный адрес сервера.
3. Нажмите **Refresh Models / Test Connection**. В разделе **Models on ComfyUI** появятся списки файлов для загрузчиков выбранного workflow pack: основная модель, текстовый энкодер, VAE, апскейлер и выделение объекта.
4. Выберите нужные файлы и нажмите **OK**. Настройки сохраняются отдельно для каждого адреса сервера и workflow; **Cancel** не применяет изменения выбора моделей.

**Workflow default** сохраняет заданное workflow имя. Если этот файл находится в единственной подпапке на сервере, Composa использует полное имя из серверного списка. Если одно имя найдено в нескольких подпапках, требуется явный выбор. Пропавшая явно выбранная подпапка не заменяется другой автоматически.

**Workflow by task** в **AI → ComfyUI Settings** задаёт workflow pack отдельно для генерации, заливки, Image Edit, удаления объекта, Expand и других операций. **Use default workflow** наследует общий **Default workflow**. Списки содержат только packs, поддерживающие задачу. Выбор на плавающей панели относится к Gen Fill; выбор в окне генерации — к текущей операции. Они не меняют остальные назначения. При исчезновении явно выбранного pack нужно выбрать другой: автоматической подмены, в том числе платной, нет.

В **Generate Image** и **Image Edit** есть тот же блок **References**, что на плавающей панели: до шести картинок по порядку, добавление из проводника, Ctrl+V или перетаскиванием, предпросмотр по нажатию на миниатюру и удаление крестиком. Список общий для этих окон; лимит и настройки размера референсов в Advanced прежние.

Инструмент **Object Selection AI** находится в группе Magic Wand. При начале прямоугольника удерживайте **Shift**, чтобы добавить полученную маску, или **Alt**, чтобы вычесть её. Без модификатора маска заменяет прежнее выделение. Shift не делает прямоугольник квадратным; Alt имеет приоритет при одновременном нажатии. Старое выделение не меняется до успешного результата, объединение отменяется одним Ctrl+Z.

Модель в списке загрузчика не обязательно подходит всем workflow. Например, SDXL не становится совместимым с FLUX.2 от выбора в списке UNETLoader. Основная модель, энкодер и VAE должны соответствовать архитектуре workflow и поддержке установленного ComfyUI.

Перед отправкой исходных картинок Composa проверяет узлы и модели конкретной операции. Отсутствие генеративной модели не мешает отдельному workflow апскейла. После установки новых файлов или узлов обновите списки; при необходимости перезапустите ComfyUI.

## Один компьютер и локальная сеть

- На одном компьютере обычно используется `http://127.0.0.1:8188`.
- На другом компьютере нужен адрес машины с ComfyUI, например `http://192.168.1.50:8188`. `127.0.0.1` всегда означает текущий компьютер, а не соседний.
- ComfyUI должен слушать интерфейс локальной сети, и его порт должен быть разрешён в брандмауэре сервера. Не открывайте его в интернет для этой задачи.
- Копировать веса на компьютер с Composa или подключать сетевой диск не требуется. Исходные изображения отправляются по HTTP, результат скачивается с сервера.

Папки `models`, `shared` и произвольные дополнительные каталоги настраиваются **на стороне ComfyUI**. Для portable/manual установок используется `extra_model_paths.yaml`; ComfyUI Desktop имеет собственные настройки хранилищ. Просто указать папку на клиенте недостаточно: сервер должен знать её и иметь к ней доступ. См. [официальные настройки дополнительных путей](https://docs.comfy.org/basic-concepts/models#adding-extra-model-paths).

## Если список пуст или модель не найдена

- **Нет подключения:** проверьте, запущен ли ComfyUI и открывается ли его адрес с компьютера с Composa.
- **Missing node:** установите нужный custom node в ComfyUI и его зависимости, затем перезапустите сервер.
- **Not found or ambiguous:** выберите полный идентификатор файла из списка. Composa не выбирает другую модель наугад.
- **Loader does not report a model list:** установленный узел не предоставил список через API. Проверьте узел и его настройки в самом ComfyUI.
- Если файлы отсутствуют и в выпадающем списке соответствующего узла в браузере ComfyUI, исправлять нужно его пути к моделям.

## Чат-ассистент — отдельное подключение

GGUF-модель ассистента не относится к этим спискам ComfyUI. В **Assistant Settings** можно указать локальный файл GGUF и исполняемый файл llama.cpp через **Browse…**, либо использовать уже запущенный сервер или API-провайдера. Удалённому ассистенту локальный путь к весам не нужен; автоматически запускать llama.cpp разрешено только на текущем компьютере.

## Операции, варианты и видеопамять

- **AI → ComfyUI Settings** — подключение, выбор моделей и **Additional image-editing prompt**: редактируемая приписка к промтам с отдельным переключателем. По умолчанию просит сохранять цветокоррекцию, резкость и исходную текстуру, не добавлять шум. Это текст для модели изображения, не отдельная роль system в чате; новая генерация без исходника и референсов его не получает. Отключение не отменяет инструкции конкретной операции, например удаления чёрного пятна.
- **AI → AI Advanced** или **Advanced…** на плавающей панели — мегапиксели, размер референсов, seed, mask context/grow/blend, conditioning blur, color match и режим вариантов.
- **Variants: 1 / 3** задаёт число результатов. **List** (по умолчанию) последовательно выполняет генерации с разными seed, повторно используя загруженные картинки. **Batch** обрабатывает три варианта вместе и требует больше VRAM. Нестандартный workflow без поддерживаемого latent batch нужно запускать в List; программа сообщает об этом до отправки изображений.
- Варианты появляются в общей группе: виден только первый. Кнопки **1, 2, 3** в верхней строке переключают результат; исходное изображение остаётся нетронутым. Одна отмена возвращает состояние до всей генерации. Ошибка/отмена до вставки результатов не оставляет частично созданных слоёв.
- **Upscale…** предлагает только **×2 / ×4**. Без выделения изменяется размер изображения и холста. С выделением результат помещается в исходную область через её маску, холст не увеличивается.
- Штатный узел ComfyUI апскейлит плитками. Масштаб внутри модели задан весами: модель ×4 всё равно вычисляет ×4, даже если конечный результат ×2. Composa не уменьшает исходник перед моделью; итоговый размер задаётся до сохранения/скачивания результата. Для минимального расхода памяти при ×2 выбирайте настоящую модель ×2. Поддержка файла зависит от загрузчика ComfyUI/Spandrel, а не только от расширения.

## Масочное редактирование и видимая граница

Встроенный workflow FLUX.2 Klein ограничивает генерацию маской через **InpaintModelConditioning / noise_mask**, используя закодированный исходник, а не пустой latent всего фрагмента. Composa сохраняет границы контекста в исходных пикселях, вырезает его штатными нодами ComfyUI, округляет размер до 16 для VAE и возвращает декодированный фрагмент в исходные координаты. Выход не склеивается заранее с исходником: мягкий переход выполняет отдельная редактируемая маска слоя. При её удалении видны все полученные пиксели фрагмента, а не уже вырезанное изображение. За пределами фрагмента остаётся исходный контекст, не новый результат модели.

- **Mask grow** расширяет область замены. Для Remove выделяйте объект целиком, включая ореол и тень, которую хотите убрать.
- **Mask conditioning blur** (по умолчанию 16 px для FLUX) смягчает маску, ограничивающую sampling, в разрешении входного фрагмента модели.
- **Mask blend** (по умолчанию 48 px для FLUX, 8 px для GPT) задаёт финальный переход маски слоя в исходных пикселях. Remove сохраняет непрозрачный центр области замены с мягким переходом наружу. Fill оставляет итоговую область внутри выделения. Окружение crop расширяется с учётом перехода; sampling-маска не становится альфой слоя и не применяется повторно.
- Область sampling получает дополнительный запас под всю зону перехода в разрешении модели; это не расширяет финальную маску вставки. Для Remove чёрная заливка использует отдельную жёсткую маску и остаётся внутри области, которую модель полностью перегенерирует. Это предотвращает остаточный серый контур из частично сохранённого чёрного края.
- **Mask context** (по умолчанию 2) определяет окружающий контекст с запасом для мягкого края, ограниченный холстом. Большой контекст при прежнем MP уменьшает детализацию объекта; слишком маленький мешает модели продолжать фон. Пункт **Show AI context bounds after selection** в ComfyUI Settings управляет пунктирной рамкой входного контекста Fill.
- **Color match** по умолчанию off. Встроенный локальный workflow согласует окружение существующим алгоритмом для обоих включённых вариантов; они пока не задают отдельные степени силы. При намеренной смене цвета или освещения используйте off.

Начальный размер — **Original size**, Mask grow — 16 px для FLUX и 4 px для GPT. Настройки масок этих pack сохраняются раздельно. LoRA по умолчанию выключены; двойной щелчок по силе открывает ввод числа без дополнительной кнопки 123. Generate Image Advanced не показывает маски и контекст. Начальный pack для Generate Image — GPT, остальных задач — FLUX; их можно изменить по отдельности. Эти значения применяются к старым настройкам один раз, последующие правки пользователя сохраняются.

Для **FLUX Gen Fill** начальные значения уточнены отдельно: **Mask grow 4 px, Mask blend 8 px, Mask conditioning blur 4 px, Mask context 1,2**. Они используются в Advanced, запросе генерации и рамке контекста; Expand, другие операции FLUX и GPT сохраняют прежние значения.

Теперь все параметры Advanced и генерации сохраняются **отдельно для каждой операции и WF**. Старые значения остальных операций переносятся без сброса. Для **FLUX Expand** начальные значения: **Original size, References 1 MP, List, Mask grow 16 px, Mask blend 48 px, conditioning blur 16 px, Color match subtle, Mask context 2,0, Seed −1**. Изменение Fill не меняет Expand и наоборот; переключение WF восстанавливает его собственные значения. В заголовке Advanced указана операция.

В **Original size** фрагмент FLUX и его маска больше не растягиваются до кратности 16 и обратно: техническое дополнение справа/снизу удаляется при возврате результата в сохранённые координаты. Это устраняет смещение от двойного масштабирования самой программой, но модель всё ещё может перерисовать детали. MP и явно выбранный размер Expand по минимальной стороне по-прежнему предполагают масштабирование.

Локальное согласование Remove больше не синтезирует зерно. Однако шум, нарисованный самой моделью, приписка к промту и правильная маска не гарантированно устраняют: он также зависит от модели/квантизации, VAE и размера crop. Здесь нет автоматического шумоподавления, способного размазать полезную текстуру.

## Смарт-объекты

**Layer → Convert to Smart Object** сохраняет редактируемые слои внутри проекта `.cmps`. Двойной щелчок по миниатюре или **Edit Smart Object Contents…** открывает содержимое во вкладке. Правьте слои и нажмите **Ctrl+S / Save contents** — обновятся связанные экземпляры в родительском документе, сохранив наружную трансформацию, маску и эффекты. После этого сохраните сам родительский проект.

Обычная копия использует общий источник. **New Smart Object via Copy** создаёт независимый. **Rasterize Layer** отключает редактируемый источник, сохраняя изображение; отмена возвращает смарт-объект. Вложенное содержимое и общий источник сохраняются внутри одного проекта, внешние файлы не требуются. Это собственные встроенные объекты Composa, не полноценный импорт Photoshop Smart Objects или связанные внешние файлы. Новые проекты имеют формат 7: для их открытия нужна эта или более новая сборка; старые проекты продолжают открываться.
# CHAT GPT 2.5 — платный pack без локальных моделей

Выберите **CHAT GPT 2.5** внизу плавающей панели. Нужен ComfyUI с официальной нодой **OpenAIGPTImageNodeV2**, в которой доступен **gpt-image-2.5-sunburst**. Обновите ComfyUI, если этого варианта нет. Локальные UNET/CLIP/VAE и LoRA для GPT не требуются; Advanced показывает качество и размеры, поддерживаемые сервером.

В **AI → ComfyUI Settings** вставьте **Comfy.org API key** в поле Session API key — только на текущий запуск. Для постоянного подключения задайте на компьютере с Composa переменную `COMPOSA_COMFY_API_KEY`; в настройках можно выбрать другое имя переменной. Ключ создаётся на [platform.comfy.org](https://platform.comfy.org/), это не ключ OpenAI. Вход в браузере ComfyUI не авторизует запросы Composa. На чужой/публичной сети используйте HTTPS.

Каждый из 1/2/3 вариантов оплачивается. List выполняет отдельные запросы, Batch передаёт `n` общей ноде. Оценка стоимости берётся из данных ноды; если сервер передаёт цену в ходе выполнения, показывается она. **Баланс кредитов локальный API ComfyUI не отдаёт** — смотрите Credits в самом ComfyUI. Кредиты Comfy.org и токены OpenAI — разные величины. Undo не возвращает списанную оплату.

При редактировании исходный фрагмент — **image 1**, пользовательские референсы — **image 2, image 3…**. При генерации с нуля первый референс — **image 1**. GPT получает прямоугольный фрагмент вокруг выделения и референсы, без отдельной маски, картинки-подсказки и инструкций с координатами. **GPT context padding** в Advanced задаёт контекст с каждой стороны в исходных пикселях: по умолчанию 0 px, диапазон 0–1024 px. Он независим от настроек контекста FLUX и растушёвки. Обычный Gen Fill получает исходный фрагмент без чёрной заливки; Remove/Expand сохраняют чёрную область. Composa возвращает все пиксели результата в исходные координаты и размер, с отдельной мягкой маской слоя. [Подробности](../ai/engines/chatgpt-image-2.5/README.md).

В GPT Gen Fill пиксели вне выделения сохраняются исходными независимо от ответа модели. Финальный **Mask blend** идёт внутрь границы, отдельно от контекста входного фрагмента; маленькое выделение сохраняет непрозрачный центр. Для Remove/Harmonize/Relight значение **Mask grow** дополнительно разрешает изменение указанного запаса вокруг объекта. Уже вклеенный результат не растушёвывается второй раз. Растяжение ответа с неверными пропорциями запрещено — программа сообщит об ошибке и не применит правку; списанная сервером оплата при этом не возвращается.

**Generate Image** по умолчанию использует размер холста, MP меняет площадь с сохранением пропорций. GPT получает явные **Custom** размеры вместо Auto. При ограничениях модели окно показывает реальный размер запроса: шаг 16, стороны 480–3840 px, площадь 0,655–8,294 MP, пропорции от 1:3 до 3:1. Более широкий полный холст потребует FLUX. Качество GPT доступно в основном окне; отдельного параметра «интеллекта» у image-ноды нет. Seed находится только в Advanced; для GPT не показывается, поскольку сервер его не использует.

Стоимость показывается как **кредиты / доллары**. Пересчёт использует [официальное соотношение Comfy](https://support.comfy.org/articles/1982697177-partner-nodes-pricing): 211 кредитов = $1. Предварительная оценка — диапазон из таблиц ноды, а не фиксированная цена или лимит расходов.

## Expand и полное редактирование

**Generative Expand** доступен через AI и дополнительные операции плавающей панели. Можно выбрать FLUX или GPT прямо в окне.

- **Empty area only** включён по умолчанию. В модель отправляются чёрное пустое пространство, мягкая маска и контекст. Имеющееся изображение сохраняется. Работает и с расширенным Crop, и с прозрачным пространством внутри существующего холста, например после уменьшения слоя. Выделение может ограничить заполнение пустоты внутри холста. Невыделенная пустота остаётся прозрачной, чёрный вход не становится чёрной заливкой результата.
- **Regenerate whole expanded image** передаёт всё изображение после Crop без маски. Модель может изменить весь кадр. По умолчанию используется получившийся размер холста.
- Размер задаётся по минимальной стороне: **768, 1024, 1280, 1536, 1792, 2048 px**; по умолчанию для масочного режима — 1024. Итоговый размер холста не меняется от выбора разрешения генерации. Расширение холста и все варианты отменяются одним Ctrl+Z.

Без выделения доступен **Image Edit**: передаётся всё изображение. Remove, Change Background, Harmonize и Relight тоже работают без маски. При Change Background без выделения сохранение объекта обеспечивается промтом, не точной локальной маской; для гарантированно неизменного объекта сначала выделите его — тогда он вернётся отдельным исходным слоем. Только **Gen Fill** требует выделения.

Дополнительный промт хранится отдельно для каждого workflow pack в ComfyUI Settings: можно включить, выключить, изменить или восстановить общий исходный текст. Это приписка к промту изображения, не отдельная системная роль чата. Старые пользовательские настройки сохраняются. Везде варианты выбираются рядом с Generate одной составной кнопкой. LoRA доступны для FLUX, до трёх штук; сила **0–3**, число можно ввести через **123** или двойной щелчок по полю.
