# FLUX.2 Klein

Production Engine Pack for the Intel Arc ComfyUI installation used to validate Composa stage 2.

- Generation and image editing use `flux-2-klein-9b_int8_convrot.safetensors`, Qwen 3 8B FP8 and the FLUX.2 VAE.
- Advanced → Memory use: Auto chooses Lower VRAM on Intel XPU, Standard keeps ordinary server placement, and Lower VRAM keeps the text encoder on CPU and uses stock tiled VAE nodes. CPU encoding may take substantially longer. These modes retain the selected model filenames; no external ComfyUI files are changed.
- Masked requests use stock image/mask nodes at runtime without a Pixaroma dependency. Source-coordinate context bounds include mask growth, at least 24 pixels of context, seam room and the proportional context setting. Edge crops shift within the canvas to preserve that room. Original-size crops receive only right/bottom padding to multiples of 16 (minimum 64 per side). MP is the total crop budget including context; Expand pixel sizes specify the longest side. Padding is extracted before resampling the returned image, so cubic interpolation cannot pull padding into the seam. All decoded dimensions are validated.
- The supplied Pixaroma workflow's masked pipeline is retained: source VAE encoding → ReferenceLatent → InpaintModelConditioning → KSampler, with Euler/simple and the model's native schedule. Mask growth is in source pixels, nearest-neighbour resize precedes Gaussian blur, and blur is in generation pixels. The previous binary noise-halo override is removed. Final mask-mode coverage has an opaque grown core and an outward smooth seam; raw decoded pixels remain recoverable under the editable layer mask. Color matching remains a separate optional local correction.
- Advanced/generation settings are independent for every task and workflow pack. Existing values seed profiles without a reset. Generative Fill defaults remain Mask grow 4 px, Mask blend 8 px, conditioning blur 4 px and Mask context 1.2. Expand starts with Original size, 1 MP references, List execution, 16/48/16 px, context 2, Color match subtle and random seed. Later profile edits persist independently. Pixel-identical equivalence to Pixaroma is not claimed: Composa uses uniform content scaling plus technical padding and a chamfer approximation for the seam distance.
- Editing and inpainting accept zero to six ordered visual references. Missing optional branches are pruned before the workflow is queued.
- Upscale can use either installed `4x-UltraSharpV2.safetensors` or `4x_NMKD-Siax_200k.pth`, selected in ComfyUI Settings. Without a selection it resizes the document in the same undo transaction as the generated layer; with a selection it enhances only that patch and returns it at the original bounds as a masked layer without resizing the canvas.
- Select Subject and Object Selection use native ComfyUI background removal with `birefnet.safetensors` and return an ordinary editable Composa selection. BiRefNet is MIT-licensed; unlike BRIA RMBG 2.0 it does not impose a non-commercial model restriction.
- Change Background with a selection uses a separate background-generation workflow with zero to six optional references, without the original subject as model conditioning. The complete scene is fitted beneath the untouched original-subject layer. Without selection it uses full-image editing; no implicit segmentation is run. Image Edit, Remove, Harmonize and Relight can also edit the whole image without selection.
- Match to Scene is local and non-generative: it adds clipped Exposure, Color Balance and, when useful, Focus or Grain adjustment layers in one undo step.
- Expand offers masked empty-area-only generation (default, 1024 px longest side) or whole-image regeneration (default original expanded size). The mode can fill existing transparent canvas, optionally restricted by a selection, or an expanded Crop. Empty input is opaque black; a separate soft layer mask preserves existing content while keeping the decoded crop recoverable. All canvas changes and variants undo together. Size choices are 768–2048 px longest side. Legacy script/settings property names containing MinimumSide remain readable with the new longest-side semantics.
- LoRAs: off by default, up to three model-only adapters from the connected server, individual and global toggles, strengths 0–3. Drag the strength or double-click for numeric entry. The additional prompt is saved independently for this pack in ComfyUI Settings. Generation windows use joined Generate + 1/2/3 controls; Seed stays in Advanced. Generate Image hides mask/context settings.
