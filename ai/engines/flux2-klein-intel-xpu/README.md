# FLUX.2 Klein

Production Engine Pack for the Intel Arc ComfyUI installation used to validate Composa stage 2.

- Generation and image editing use `flux-2-klein-9b_int8_convrot.safetensors`, Qwen 3 8B FP8 and the FLUX.2 VAE.
- Masked requests use stock image/mask nodes at runtime. Source-coordinate context bounds are saved before generation. Original-size crops are padded only at the right/bottom to multiples of 16 (minimum 64 per side), without resampling image or mask; the technical padding is discarded when decoded pixels return to the exact saved bounds. MP and explicit Expand minimum-side sizes intentionally scale to their requested budget. Templates retain the older crop/stitch definitions for compatibility, but Composa exports the decoded crop rather than a baked stitch for this bundled pack.
- Klein's image-edit reference conditioning and an encoded source latent with a noise mask are retained. Sampling coverage is separate from the final editable layer mask. Removing or painting that layer mask reveals the generated context pixels, not a pre-cut composite. Remove conditions an opaque black repair area and retains an opaque replacement core with a soft outer transition.
- Advanced/generation settings are independent for every task and workflow pack. Existing values seed the other profiles without a reset. Generative Fill defaults remain Mask grow 4 px, Mask blend 8 px, conditioning blur 4 px and Mask context 1.2. Expand starts with Original size, 1 MP references, List execution, 16/48/16 px, context 2, Color match subtle and random seed. Expand color matching compares against its expanded source context. Fill keeps final coverage inside the original selection; context and sampling halos do not enlarge final coverage. Later profile edits persist independently.
- Editing and inpainting accept zero to six ordered visual references. Missing optional branches are pruned before the workflow is queued.
- Upscale can use either installed `4x-UltraSharpV2.safetensors` or `4x_NMKD-Siax_200k.pth`, selected in ComfyUI Settings. Without a selection it resizes the document in the same undo transaction as the generated layer; with a selection it enhances only that patch and returns it at the original bounds as a masked layer without resizing the canvas.
- Select Subject and Object Selection use native ComfyUI background removal with `birefnet.safetensors` and return an ordinary editable Composa selection. BiRefNet is MIT-licensed; unlike BRIA RMBG 2.0 it does not impose a non-commercial model restriction.
- Change Background with a selection uses a separate background-generation workflow with zero to six optional references, without the original subject as model conditioning. The complete scene is fitted beneath the untouched original-subject layer. Without selection it uses full-image editing; no implicit segmentation is run. Image Edit, Remove, Harmonize and Relight can also edit the whole image without selection.
- Match to Scene is local and non-generative: it adds clipped Exposure, Color Balance and, when useful, Focus or Grain adjustment layers in one undo step.
- Expand offers masked empty-area-only generation (default, 1024 px minimum side) or whole-image regeneration (default original expanded size). The mode can fill existing transparent canvas, optionally restricted by a selection, or an expanded Crop. Empty input is opaque black; a separate soft layer mask preserves existing content while keeping the decoded crop recoverable. All canvas changes and variants undo together. Size choices are 768–2048 px minimum side. The dialog can switch between FLUX and GPT. The active Crop frame refits to the completed canvas.
- LoRAs: off by default, up to three model-only adapters from the connected server, individual and global toggles, strengths 0–3. Drag the strength or double-click for numeric entry. The additional prompt is saved independently for this pack in ComfyUI Settings. Generation windows use joined Generate + 1/2/3 controls; Seed stays in Advanced. Generate Image hides mask/context settings.
