# FLUX.2 Klein · Intel XPU

Production Engine Pack for the Intel Arc ComfyUI installation used to validate Composa stage 2.

- Generation and image editing use `flux-2-klein-9b_int8_convrot.safetensors`, Qwen 3 8B FP8 and the FLUX.2 VAE.
- Fill, removal, harmonization, relighting and expansion use `InpaintCropImproved` / `InpaintStitchImproved`. The crop is padded internally, sampled at dimensions divisible by 16, and stitched back to the exact source canvas, so odd document sizes are not silently cropped.
- Masked edits use Klein's image-edit reference conditioning and an encoded source latent with a noise mask. Installed Pixaroma crop/stitch nodes are preferred automatically; Improved nodes are the fallback for missing nodes or faint masks. Mask hole filling is disabled. Remove hides the selected pixels with opaque black; the output preserves the stitcher's blending margin without a second soft mask.
- The inpaint mask grows by 8 px and blends over 32 px by default. Mask context is 2× the selection bounds by default, giving the model surrounding pixels for coherent reconstruction. All three values are configurable in Advanced settings.
- Editing and inpainting accept zero to six ordered visual references. Missing optional branches are pruned before the workflow is queued.
- Upscale can use either installed `4x-UltraSharpV2.safetensors` or `4x_NMKD-Siax_200k.pth`, selected in ComfyUI Settings. Without a selection it resizes the document in the same undo transaction as the generated layer; with a selection it enhances only that patch and returns it at the original bounds as a masked layer without resizing the canvas.
- Select Subject and Object Selection use native ComfyUI background removal with `birefnet.safetensors` and return an ordinary editable Composa selection. BiRefNet is MIT-licensed; unlike BRIA RMBG 2.0 it does not impose a non-commercial model restriction.
- Change Background with a selection uses a separate background-generation workflow with zero to six optional references, without the original subject as model conditioning. The complete scene is fitted beneath the untouched original-subject layer. Without selection it uses full-image editing; no implicit segmentation is run. Image Edit, Remove, Harmonize and Relight can also edit the whole image without selection.
- Match to Scene is local and non-generative: it adds clipped Exposure, Color Balance and, when useful, Focus or Grain adjustment layers in one undo step.
- Expand offers masked empty-area-only generation (default, 1024 px minimum side) or whole-image regeneration (default original expanded size). The mode can fill existing transparent canvas, optionally restricted by a selection, or an expanded Crop. Empty input is opaque black, and masked output is constrained to the empty area after stitching. All canvas changes and variants undo together. Size choices are 768–2048 px minimum side. The dialog can switch between FLUX and GPT.
- LoRAs: up to three model-only adapters from the connected server, individual and global toggles, strengths 0–3. Drag/double-click the strength or use **123** for numeric entry. The additional prompt is saved independently for this pack in ComfyUI Settings. Generation windows use joined Generate + 1/2/3 controls; Seed stays in Advanced.
