# Krea 2 Turbo

Local ComfyUI text-to-image generation. Put the weights in these folders on the ComfyUI server and refresh the model list in AI Settings.

- `models/diffusion_models/krea2_turbo_int8_convrot.safetensors`
- `models/text_encoders/qwen3vl_4b_fp8_scaled.safetensors`
- `models/vae/qwen_image_vae.safetensors`

[ComfyUI model downloads and reference workflow](https://docs.comfy.org/tutorials/image/krea/krea-2)

The generation prompt enhancer follows Krea's recommendations for natural-language expansion and quoted lettering. [Prompting guide](https://github.com/krea-ai/krea-2/blob/main/docs/prompting.md) · [Expansion instructions](https://github.com/krea-ai/krea-2/blob/main/docs/expansion.txt)
